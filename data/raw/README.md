# Raw data

Place the two source files in this directory using these exact names:

```text
cl.txt
champions_league_matches.csv
```

Sources used for this project:

1. **OpenFootball — UEFA Champions League 2025/26**  
   Complete competition results: 189 matches across the league phase and knockout stages.  
   Repository: https://github.com/openfootball/champions-league

2. **Champions League Matches 2025–2026**  
   Detailed 144-match league-phase dataset with venue, referee, possession, shots on target and saves.  
   Dataset page: https://www.kaggle.com/datasets/johntocci/champions-league-matches-2025-2026

The raw data files are intentionally ignored by Git. This repository stores the processing code, SQL, documentation and derived analysis rather than redistributing the source datasets.
